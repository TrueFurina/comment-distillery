# 规则溯源台账（Rule Provenance）

> 建立：2026-09-26（P2 方法论去过拟合）
> 为什么有这份文件：**SKILL.md 里多数规则只被 1 战验证过**。个案被写成铁律会误导后续使用者——
> 一条只在单个视频上成立的经验，被当成普适规律写进 skill，代价是后续每一战都要为它买单。
>
> **升级门槛**：≥2 战独立验证 → 进 SKILL.md 正文为**铁律**；仅 1 战 → 标记 `[待复现]`，
> 详述移入本文，SKILL.md 只保留一行指针。机制性事实（操作系统/工具行为）标 `[环境]`，不适用战次门槛。

## 2. 待复现（仅 1 战证据，**不是铁律**）

> 这些条目**可能是真的，但样本量 = 1**。使用时当作"值得检查的假设"，不要当作"已知规律"。
> 复现方式写在每条后面——**下一次遇到同类语料时顺手验一下，第二次成立即可升级为铁律**。

| # | 观察 | 仅验证于 | 复现判据（第二次怎么算成立） |
|---|---|---|---|
| W1 | **meta 噪音识别**：头部若在争论形式（用词/口音/标题/长相）而非内容，说明语料被跨圈层推流 | 战3（清北 discouraged） | 另一个语料头部同样出现"形式争论 > 内容争论"，且长尾确实存在被稀释的目标受众观点 |
| W2 | **多语料合并浮现单语料看不到的结构** | 战4（薪资 903 + 43 岁被裁 8038 → "初级岗位消失 → 成长通道断裂"） | 另一组合并后出现单份中不存在、且可在两份语料里分别找到部分证据的闭环结论 |
| W3 | **楼中楼的两个用途要分开开采**（反例来源 / 深度解析富矿） | 战7（火柴人 VS 数学） | 另一语料的楼中楼同时贡献"反驳"与"最深解析"，且后者在一级评论区确实不存在 |
| W4 | **低赞长文筛选会捞到粘贴板污染**（0 赞超长文本里混有歌词/攻略/复读） | 战7（增补卷） | 另一语料的低赞长文区同样出现"无具体指称的叙事性长文"，且人工判定为零信息 |
| W5 | **注意力漂移 2.5×**（与主题零相关的争论楼拿到的赞是实质辩论的 2.5 倍） | 战7（单样本：语法争论楼 2,867 赞 vs 教育价值辩论 1,142 赞） | 至少再 2 个语料上观测到同类"跑题楼点赞 > 主题辩论"，且倍数落在同一量级 |

> ⚠️ **W5 尤其危险**：它是**单个样本的一个比值**。目前不能当常数用，不能写进任何对外材料当结论。

## 4. 与 ROADMAP P2 的偏离说明（诚实记录）

ROADMAP 原文要求"仅 1 战的先进 `cases/notes/`，标注待复现"。实际执行为**保留在 SKILL.md，但集中放进独立的「待复现观察」章节并打 `[待复现]` 标记**，未移出。

**偏离理由**：`cases/` 已被 `.gitignore` 排除在仓库外，把规则移进去等于让 skill 使用者**完全看不到**这些踩过的坑——保留标记比删除更诚实，因为标记已经把不确定性完整传达给了读者。

**代价**：SKILL.md 的篇幅略长。已接受。

## 5. 维护方式

- 每完成一战，回到本文件：在 §2 找有没有被复现的（有 → 移入 §1，并在 SKILL.md 去掉 `[待复现]` 标记）；
- 新观察到的单次现象 → 先进 §2，不要直接写进 SKILL.md 铁律区；
- `scripts/check_rule_tags.py` 会机验 SKILL.md 无"裸铁律"（条目缺标记即 FAIL，CI 卡死）。
