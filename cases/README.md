## ⚠️ 先读：这里只有「产物」，没有原始语料

本目录**只公开产出层的文档**：

| ✅ 公开 | ❌ 不公开 |
|---|---|
| 各战最终指南（`.md`） | 原始评论 CSV |
| 设计留档（方案论述 / 路线图 `.md`） | 流水线中间产物（`all_comments.txt` / `id_map.json` / `stats.json`） |
| — | 过程脚本（`*.py`）、图表（`*.svg`）、会话记忆（思考快照） |

**依据**：[`../docs/compliance.md`](../docs/compliance.md) §2 —— **不得二次分发原始语料**。
原始文本的著作权归原作者与平台所有；本项目的产出是**观点提炼与结构化**，不是原作的复制或汇编。

因此你**拿不到原始 CSV 来复现跑分**。要验证引用真实性，请用你自己的语料跑
[`../scripts/verify_citations.py`](../scripts/verify_citations.py)——它对任何 CCF 格式语料都适用。
